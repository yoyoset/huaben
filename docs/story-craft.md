# 标杆作品的设定规律 → 话本的设计规范

2026-10-03 用户要求:把《海贼王》《火影忍者》《死神》这类传世长篇的复杂设定规律挖出来,补全我们欠缺的部分(力量构成、故事框架、节奏)。
起因:架构方连续三版设定被否——"当铺"只有神秘层、没有力量感;"节气"容量太小;"吃"不完整。共同的病是**只设计了一个点子,没有设计一个体系**。

本文分两部分:前六节是规律(为什么这些作品能连载上千话还让人追),第七节是规范(话本每本书的设计稿必须填满的清单)。
写全书设计(`stories/<书名>/design.md`)和每一批章纲之前,都要对照第七节。

用户的固定口味(不随书变):不要现代;有趣;不苦大仇深;爽;有想象力;要预期之外。规律里与此冲突的地方(如"导师之死"),在各条里写了怎么改。

## 零、先分清两种流派(2026-10-03 用户:"不用生搬硬套海贼王的全部套路",要看火影、死神、幽游白书的共性)

这份文件第一版把四部作品混在一起讲,其实它们是两种骨架。**话本以"据点战斗流"为主骨架**,航海冒险流的东西只挑着用。

| | 据点战斗流:幽游白书、死神、火影 | 航海冒险流:海贼王 |
|---|---|---|
| 主角的位置 | 有一个**家**(人间界、空座町、木叶),在一个**组织**里有身份(灵界侦探、死神代理、忍者) | 永远在路上,自己就是组织 |
| 故事怎么动 | **出征与回家**:接任务、闯敌营、敌人打上门 | 一站一站往前走,每站一个新世界 |
| 队伍 | **三四个人的固定小队,很早成形**,其中一两个原本是敌人 | 伙伴一路越攒越多 |
| 看点 | **格斗与情义**:一对一的对决、擂台、修行、宿敌 | 奇观、冒险、世界之谜 |
| 篇章类型 | 任务 → 大会/考试 → 闯营营救 → 家被打上门 → 大战,**轮着来** | 抵达 → 卷入 → 总攻 → 宴会,每站重复 |
| 真相层 | **人的秘密**:主角的血脉、体内的东西、组织的罪、反派是走歪了的前辈 | **世界的秘密**:历史的空白、终点有什么 |
| 进度感 | 赛程表、处刑日、楼层、敌方干部的编号——**读者随时知道走到哪了** | 地图上的位置 |

### 据点战斗流的十二条共性(三部作品都有的才算)

1. **开头是小案子。** 头二三十话是一件件独立的小任务或小事件(幽助办灵异案、一护除虚、鸣人抓猫护送),轻松、好笑、有人情味,
   用来把主角和身边人立住;然后才滑进第一个大篇章。不是一上来就大格局。
2. **主角是个不良少年式的局外人,被拉进"另一边"的世界,并被给了一个身份。** 他有义气、嘴硬、成绩差、被人看不起,但从不自怜。
   "另一边"是个有官衔、有规矩的衙门(灵界、尸魂界、忍村),主角是里面最不守规矩的那个。
3. **固定小队,早早凑齐,各有一路功夫。** 幽助—桑原—藏马—飞影;一护—石田—茶渡—织姬(加露琪亚、恋次);第七班。
   其中至少一个是**被打败后变成同伴的前敌人**,一个是**又弱又好笑但最重情义的**(桑原),一个是**比主角更酷的**(飞影、佐助),读者往往最爱他。
4. **昨天的敌人是今天的战友。** 打过一场、互相认可的对手,在后面的篇章会回来帮忙(酎与阵、我爱罗、白哉、格里姆乔)。
   所以每个值得一写的对手都要留活口、留性格——他是以后的援军,也是老读者的福利。
5. **敌方是一个有座次的小团体,从低到高一个个打。** 四圣兽、户愚吕队、仙水七人、音忍四人众、十刃、晓。
   每个席位对上小队里的一个人(配对),一场一场结算。**座次就是进度条。**
6. **篇章类型轮换,不重复同一种。**
   - 任务/事件(小,立人物);
   - **大会/考试**(暗黑武术会、中忍考试):擂台赛程把一大群新人物和新本事一次亮出来,通常被更大的阴谋打断或借题发挥;
   - **闯营营救**(救露琪亚、追回佐助、救雪菜):目标清楚、有死线、敌营一层层守关;
   - **家被打上门**(仙水开魔界之门、佩恩袭村、蓝染进攻空座町):前面攒下的所有人都出场;
   - 大战与终局。
7. **有倒计时。** 武术会的赛程、处刑的日子、魔界之门还有七天打开。时间限制让修行有紧迫感、让每一场不能拖。
8. **招牌招是师父传的,而且有次数或条件限制。** 灵丸一天只能打四发;螺旋丸是师父和父亲的招;月牙天冲是刀教的。
   限制制造算计(还剩几发),传承让一个招式带着人情。之后主角把它改造成自己的。
9. **有一段明明白白的修行。** 幻海婆婆的修行、浦原和假面军团的特训、自来也带着修行。修行不是略过,是有笑点、有师徒情的正戏;
   修行的成果在下一场硬仗里第一次亮出来。
10. **主角身体里有一个危险的东西。** 幽助的魔族血、一护的虚、鸣人的九尾。它先是失控的隐患,然后是不得不借用的力量,最后是和解。
    这条线同时是神秘层、长线伏笔和人物成长,**一物三用**。血脉的真相很晚才揭开,而且改变主角对"我是谁"的认识。
11. **大反派是走在主角这条路上的前辈,走歪了。** 仙水是上一任灵界侦探;蓝染是队长;大蛇丸是木叶三忍,带土曾想当火影;
    户愚吕是幻海当年的战友。他和主角的引路人有一段旧事。打败他等于回答"你凭什么不会变成他"。
12. **主角效力的组织自己有罪。** 灵界掩盖过真相,中央四十六室与灵王的秘密,木叶高层与宇智波。中后期主角发现这一点,
    从"组织的人"变成"按自己的道理行事的人"。同理,"另一边"的怪物并不都是恶(魔界有自己的秩序,虚有心,尾兽是受害者),终局常是和解而不是杀光。

还有一条写法上的共性:**打斗会从"拼力量"演变成"解题"。** 前期比谁的灵气大、谁的招硬;中后期出现**规则型能力**
(幽游白书仙水篇的"领域":在这个范围内说了禁句就丢魂;死神的完现术与圣文字;火影的瞳术与幻术),胜负取决于看破规则。
所以力量体系里要预留一类"不讲力气讲规矩"的能力,放在中后期亮出来。

### 用两部小说验证(2026-10-03 用户:天蚕土豆、哈利波特是不是也一样)

是一样的。说明这些不是漫画的套路,是长篇连载的规律。

| 规律 | 《斗破苍穹》 | 《哈利·波特》 |
|---|---|---|
| 进度条 | 斗者到斗帝十一阶;异火榜二十三位;三年之约 | 七个学年;七个魂器;每学年的学院杯 |
| 基础层 | 斗气等级、斗技功法 | 人人都上的魔法课 |
| 神秘层 | 异火(有榜、不重样)、会进化的焚诀 | 魔杖选人、母亲留下的保护、预言 |
| 开发层 | 自己把异火融成佛怒火莲 | 跟卢平苦练守护神咒;自己办 DA |
| 家与组织 | 萧家、迦南学院 | 霍格沃茨与四个学院 |
| 引路人离场(不写死也成立) | 药老被魂殿抓走 → 全书的营救动力 | 邓布利多 |
| 体内的东西 | 戒指里的药老、吞下的异火 | 哈利自己是一件魂器;蛇佬腔 |
| 走歪了的前辈 | 魂天帝 | 伏地魔:同样是霍格沃茨的孤儿 |
| 组织的罪 / 师长的秘密 | 远古各族的旧账 | 魔法部的腐败;邓布利多的过去 |
| 大会被阴谋打断 | 内院选拔 | 三强争霸赛 → 伏地魔复活 |
| 闯营营救 / 家被打上门 | 上云岚宗;救药老 | 神秘事务司;霍格沃茨之战 |
| 招牌招从头用到尾 | 佛怒火莲 | 除你武器(连最后一战都是它) |
| 决战靠看破规则 | —— | 老魔杖认主的规矩决定了结局 |

**从哈利·波特多学一条(对"预期之外"最有用):每一卷本身是一桩谜案,谜底是"那个人不是你以为的那个人"。**
奇洛、日记本、斑斑、假穆迪、斯内普——每卷都有一个一直在读者眼前、却被看错了的人。线索全程公平地摆着,读者回头能找到。
话本每卷都要设计这样一个"看错的人",写进卷剧本的真相里。

**从天蚕土豆那里要避开的两个坑:**换地图就把旧人物清空(读者前面投入的感情作废);伙伴沦为工具人(只有主角在成长)。
这正是它不如那几部漫画耐读的地方。

### 从海贼王那里只拿三样

- **阶梯式的世界**(强者一直在更远的地方,早早被提到名字);
- **当时像玩笑的长线伏笔**,回收时改变旧场面的意思;
- **篇章结束后世界的反应**(名声传开、各方议论)——在据点流里对应"在组织里的位子变了、被通缉了、被别的势力盯上了"。

不拿:一站一岛的公式、宴会、越攒越多的大船队、以世界历史为核心的真相层。

## 一、力量体系

### 1. 三层复合(用户的归纳,是地基)

| | 基础层:人人都有、能练能比 | 神秘层:每人独一份、选不了 | 开发层:角色自己练出来的 |
|---|---|---|---|
| 火影 | 查克拉;体术/忍术/幻术;五种性质变化 | 尾兽、血继限界(写轮眼、白眼)、咒印、仙人体质 | 螺旋丸→大玉→风遁·螺旋手里剑;自创忍术 |
| 死神 | 灵压;斩、拳、走、鬼四门功夫 | 斩魄刀(每把有名字、有人格、形态各异);虚化;灭却师血统 | 始解→卍解;与刀对话、让刀认可 |
| 海贼王 | 体术、剑术、六式;三种霸气 | 恶魔果实(世上同时只有一颗,附带"旱鸭子"弱点) | 二档/三档/四档/五档;果实觉醒;把看似没用的能力玩出花 |

三层各管一件事:**基础层给力量感和名次,神秘层给意外和辨识度,开发层给成长和爽点**。缺基础层 = 没有力量感(当铺设定的病);
缺神秘层 = 千人一面的升级文;缺开发层 = 能力是发下来的,不是挣来的。

### 2. 基础层的规律

- **人人可及,所以努力有去处。** 没有神秘力量、只靠基础层练到顶的人物必须存在,而且要受人尊敬:小李和凯、索隆、更木剑八。
  他们证明基础层不是垫脚石。
- **基础层决定能不能驾驭神秘层。** 灵压不够卍解会压垮自己;查克拉不够开不了高级瞳术;体力不够撑不住档位。所以境界永远不白练。
- **后期基础层反过来成为决胜手。** 海贼王里霸气压过果实,越到后面越是霸气的对决。这样前期读者投入感情的基本功不会作废。
- **基础层要有读者一听就懂的尺度**:几个明确的大境界,加上看得见的破坏力参照(这一级能打碎什么)。

### 3. 神秘层的规律

- **不可选、不重样、与人物互为镜像。** 能力是性格和经历的外化:路飞的橡胶=不受拘束,一护的刀叫"斩月"而刀里藏着他的身世,
  我爱罗的沙=母亲的守护。**先定人物,再定他的能力**,不要反过来。
- **有分类学。** 无穷多的能力必须能归类,读者才理解得了、才会自己推演对决:果实分超人系/动物系/自然系;查克拉分五性质加阴阳;
  斩魄刀分直接攻击系/鬼道系。分类 3~5 种,类与类之间有粗略的克制关系。
- **每样能力都有硬弱点和使用条件。** 海水、时间限制、发动条件、必须喊出真名。弱点让以弱胜强成立,让战斗变成斗智。
- **它自己就是一条全书级伏笔。** 主角那一份的真面目到很后面才揭开(橡胶果实的真名、斩月的真相、九尾的来历与和解)。
  规则:主角的神秘层要有**表面的解释**(读者早期信以为真)和**底下的真相**(几百章后翻出来,并且回头看处处有迹可循)。
- **主角的那一份开头看着最没用,或者是个诅咒。** 橡胶被嘲笑,九尾让鸣人被全村排斥,一护的力量是借来的。爽感来自"所有人都看走了眼"。

### 4. 开发层的规律

- **形态有阶梯、有名字、有仪式。** 始解/卍解,二档/三档,仙人模式/尾兽模式。每个形态有一句解放语或起手式、一个一眼认得出的样子。
  读者期待的不是"变强",而是"下一个形态长什么样"。
- **每次大突破都同时是一个心结的解开。** 一护接纳体内的虚、鸣人与九尾和解、路飞在绝境里笑出来。**力量的钥匙在人物心里**,
  所以升级场面同时是情感高点。反过来说:没有内心事件的升级,读者记不住。
- **创造高于天赋。** 主角的招是自己琢磨出来的(把橡胶当泵用、把螺旋丸掺进风),经常来自失败、玩笑或别人的一句话。
- **代价明码标价。** 二档折寿、八门遁甲烧命、卍解时间有限。强招不能随便用,所以什么时候用成了戏。
- **老招不淘汰。** 螺旋丸从头用到尾,只是越变越大;橡胶手枪到最后还是那一拳。招牌招是人物的签名,升级的是它,不是换掉它。

### 5. 整个体系的规律

- **规则早公开,上限晚揭晓。** 读者很早就知道体系的基本规则(可以推演、可以争论),但更高的层次是一层层揭开的。
  而且常常是**先看见现象、几百章后才命名**:香克斯第一话瞪退海王类,"霸气"这个词很久以后才出现。回头看,作者早就知道。
- **膨胀靠"加一层",不靠"数字变大"。** 新阶段引入的是新维度(霸气、仙术、觉醒),而不是把旧数字乘十。于是老人物只要补上新维度就能跟上,不会作废。
- **强者一直都在,只是在更远的地方。** 世界阶梯(东海→伟大航路→新世界)保证新对手不是凭空冒出来的:他们早就被提到过名字。
- **战力不是一个数。** 有粗略的社会标签(悬赏金、下忍/中忍/上忍、队长/副队长),但标签经常不准——这是惊喜的来源。相性、情报、意志能翻盘。
- **力量嵌在社会里。** 忍者有村子、任务等级、考试;死神有十三队和番号;海贼有悬赏、海军、七武海、四皇。力量体系同时是职业体系、政治体系、经济体系。
  读者认识世界的方式就是认识"谁在哪个位子上"。
- **有编号的强者名单。** 十刃、晓、七武海、十三队队长、超新星。名单制造收集欲:读者会数"还有几个没出场""谁对谁"。每个席位的人设与能力必须一眼分得开。

## 二、世界

1. **阶梯式地图,而且早早亮给读者看。** 第一卷读者就知道世界有几层、终点在哪(伟大航路的尽头、五大国、尸魂界)。地图本身是对读者的承诺:你知道故事会去哪,只是不知道那里有什么。
2. **顶层有制衡结构。** 海军—七武海—四皇;五大国—晓;护廷十三队—虚圈—灭却师。主角一行是在几大势力夹缝里移动的小团体,每到一处都会扰动平衡。
3. **每个地方 = 一种奇观 + 一条本地规矩 + 一个本地的压迫或难题 + 一个有心愿的本地人。** 空岛、鱼人岛、波之国。主角不是去"打怪",是撞进一个地方的问题里。
4. **历史上有一个洞。** 空白的一百年、六道仙人、灵王。世界的过去缺了一块,有一个机构在守着这个谎。真相层就是这段历史,全书的大伏笔都指向它。
5. **终局人物第一卷就露面,而且往往是善意的面孔。** 香克斯、蓝染队长、带着面具的"阿飞"。等他的真实位置揭开时,读者会回头重读第一卷。
6. **世界会对主角的行动作出反应。** 每个大篇章结束,镜头切到别处:新的悬赏令、各方大人物的议论、报纸传遍四海。主角的成长因此是"被世界看见"的,这是长篇里最稳定的爽点之一。

## 三、人物

1. **主角:一句话的梦,第一章就喊出来,永不动摇。** "我要成为海贼王""我要当火影"。性格简单明亮,行动先于思考;身上有一处缺(孤独、被排斥)但不自怜。
   有一件**传承之物**(草帽、护额),来自一个早早离场的引路人——物件在,承诺就在。
2. **伙伴:每人 = 一个梦 + 一道旧伤 + 一个只属于他的篇章 + 团队里一个无可替代的位子。** 入伙的那一刻是他把压了很久的真心喊出来("我想活下去""帮帮我"),
   主角的回应永远是无条件的行动。伙伴的过去放在决战之前讲,给接下来那一拳装上重量。
3. **宿敌是主角的另一种可能。** 佐助和鸣人同样孤独,作了相反的选择。宿敌贯穿全书,每隔一段回来一次且更强,最后的和解或决战是全书情感的顶点。
4. **反派有道理,而且他的道理正好是主题的反面。** 佩恩的"痛才能带来和平"对鸣人的"互相理解";大反派有魅力、有信念,打败他需要主角先回答他的问题。
5. **群像靠辨识度。** 每个人一个剪影、一个口癖或笑声、一个执念。出场三句话内读者要能认出是谁。
6. **情感债的公式:压抑 N 章 → 一句话爆发 → 主角用行动回应。** 压得越久,那一句越值钱。全书最被记住的场面都是这个结构。
7. **引路人离场。** 标杆作品常用"导师之死"(自来也、艾斯)。**话本不写这个**(用户不要苦大仇深):改成失散、沉睡、被困、主动远行——
   同样提供"必须自己长大"的推力和一个重逢的远期承诺。

## 四、故事框架

> 本节的"标准骨架"是海贼王式的"一站一事"。话本以据点战斗流为主,**优先用第零节第 6 条的五种篇章类型轮换**;
> 下面这个八步骨架只在"闯营营救"和"外出任务"类的卷里套用,而且"过去篇""宴会"按需取舍。

### 1. 一个篇章(=话本的一卷)的标准骨架

1. **抵达**:新地方的奇观、规矩、一个有心愿的本地人。(轻快,笑点多)
2. **卷入**:本地的压迫者或难题露面;主角一行第一次碰壁——输一场、被分开、或者眼看着不公发生却无能为力。
3. **摸底**:知道了对手是谁、有几个干部、各自什么本事;伙伴们各自找到自己的对手(配对)。
4. **谷底**:最坏的事发生了;那个本地人(或某个伙伴)说出压了很久的真心话。
5. **过去篇**:在总攻之前,讲清楚这个人为什么是这样。
6. **总攻**:多条线一对一同时打,从弱到强依次结算;每一场是情报战(看懂对方能力 → 找到破绽 → 对方亮底牌 → 自己亮新招)。
7. **主角对首领**:分两三个回合,中间有一次反转;决胜一击落在新形态或新招的首次亮相上,并且呼应前面的心结。
8. **尾声**:宴会或告别;世界的反应(名声、通缉、各方议论);下一站的钩子。新伙伴上船。

### 2. 更大的结构

- **篇章有长有短,交替出现。** 大长篇之后接一个短而轻的,让读者喘气;若干篇章汇成一个"部",以一场所有人都卷进来的大战收尾(顶上战争、忍界大战)。
- **最强的两种发动机:营救与试炼。**
  - 营救(救露琪亚、救罗宾、追回佐助):目标清楚、有时限、敌人的据点一层层守关者——天然产生配对战和倒计时。
  - 试炼/大会(中忍考试):一次性展示同辈人、宿敌、各家本事和世界格局;然后**被一个更大的阴谋打断**。
- **修行与时间跳跃。** 一次惨败之后,主角一行分开修行,隔一段时间重聚:人人换了新样子、新本事。这是合法的"重置战力并制造期待"的手段。
- **开篇三十章要完成的事**:主角的梦和传承之物;力量体系的基本规则和主角那份"没用"的神秘力量;头两个伙伴;第一个让人恨的对手和第一次像样的胜利;
  世界阶梯和顶层格局的一瞥;至少一个终局人物露面。

### 2.5 大战役的配方(2026-10-03 用户:最感动的是海贼王的司法岛、火影的佩恩袭村、《掠天记》的上香)

这三场是同一种东西,拆开看有八样配料。**每一界至少两场这样的大战役,每场八样配齐;缺一样就只是"打得很大",不感动。**

1. **为的是一件私事,不是救世。** 抢回一个同伴、守住一个村子、给亲人上一炷香。在外人眼里不值得,在他眼里非做不可。情义压过大义。
2. **对面是整个体制,明知打不过。** 世界政府、毁掉全村的"神"、拦路的天下人。以少对多,所以每一步都是选择。
3. **这笔情感债攒了很久。** 罗宾逃了二十年,鸣人被全村冷眼了十几年。战役只是兑现的那一刻;没有前面几百章的铺垫,这一场不成立。
   所以**大战役要提前两三卷开始存钱**:那个人、那件事、那句没说出口的话,早早摆在读者面前。
4. **有一个简单、看得见的宣告动作。** 烧掉世界政府的旗、从烟尘里站出来说"我回来了"、点上那炷香。一个动作顶一万句话。
5. **被救的人自己把真心话喊出来。** "我想活下去。"在此之前他(她)一直在替别人着想、把自己往外推。
6. **全员各有一战,最弱的那个也站出来。** 每个伙伴对上一个座次,乌索普、雏田这种平时最没用的人挡在最前面的那一下,往往比主角的拳头更催泪。
7. **压到最底再翻。** 主角不在场或倒下了,所有人撑着,撑不住了——他到了。新形态在这一刻第一次亮相。
8. **打完有一个安静的尾声:认可或告别。** 全村人把曾经躲着的那个孩子抛起来;送别梅丽号。眼泪多半掉在这里,不在打的时候。

主角的态度贯穿始终:不诉苦、不讲大道理,就一句"说你想活下去"。

### 3. 伏笔

- 最好的伏笔是**当时看着像玩笑或闲笔的东西**,回收时改变旧场面的意思。
- 大伏笔挂在**物件、名字、历史**上,而不是挂在"神秘人影"上。
- 一次只让读者盯着两三个大问号;小问号快埋快收,给读者"作者说话算话"的信任,他们才愿意等大问号。

## 四点五、反转(2026-10-03 用户:"还应该有反转。你研究一下如何反转、怎么反转")

### 1. 反转是什么

读者读到的是一串事实,脑子里会自动给它们配一个"默认的解释"。**反转 = 给出一个新事实,让前面所有的事实一下子有了另一个、而且更说得通的解释。**
它不是"突然发生了一件没想到的事"(那叫意外,谁都会写),而是"原来我一直看错了"。所以反转的力气不在揭开的那一刻,在前面——
前面的每个事实都必须**同时装得下两种解释**。

一个好反转要过四关:

1. **公平**:线索早就摆在读者眼前,回头翻得到。叙述者不撒谎(人物可以看错、可以骗人,旁白不可以)。
2. **必然**:新解释比旧解释更合理。回看没有一处对不上,反而解开了几个当时觉得"有点怪"的小疙瘩。
3. **有后果**:它改变了人物接下来必须做的事,或者改变了读者对一个人的感情。只是"多知道了一件事"的反转是废的。
4. **不作废**:它不能让读者此前投入的感情变成笑话("原来是一场梦""原来他一直在演")。好反转让旧场面**更重**,不是更轻。

### 2. 十种反转(设计时从里面挑,相邻两卷的大反转不用同一种)

| 种类 | 是什么 | 标杆 | 力道来自 |
|---|---|---|---|
| **身份** | 这个人不是你以为的那个人 | 奇洛、假穆迪、斑斑;"阿飞" | 他一直在眼前 |
| **立场** | 你以为的敌人一直在护着你;你以为的自己人是对面的 | 斯内普;蓝染队长 | 把恨变成愧,把信任变成寒 |
| **动机** | 事情确实是他干的,理由和你想的相反 | 宇智波鼬灭族的真相 | 同一件事,意思全变了 |
| **局中局** | 你以为计划败了,其实败就是计划;或者你以为赢了,其实在别人局里 | "你是从什么时候开始以为……";各种盗宝戏 | 智力上的痛快 |
| **规则** | 对这样力量、这个世界怎么运转的理解是错的或只对了一半 | 橡胶果实的真名;镜花水月;斩月的真相 | 回头看处处是迹象 |
| **目标** | 拼命要的东西到手了,发现是假的、是空的,或者真正该要的是另一样 | 赢了却没救到人;抢到的是副本 | 把下一段故事逼出来 |
| **价值** | 最没用的东西、最没用的人,成了决定胜负的那一个 | 乌索普;来接他们的梅丽号 | 最暖,也最催泪 |
| **代价** | 这次胜利是有人在背后垫了东西换来的,当时没人知道 | 被逐其实是保护;有人替他扛了罪 | 迟来的感动 |
| **战中** | 一场架里的攻守易位:看破、底牌、借对方的力、换了规则 | 每一场像样的战斗 | 打斗的基本单位 |
| **叙述** | 讲述的顺序或视角骗了读者(其实这段是过去、其实说话的是另一个人) | 诺兰式 | 一本书最多用一两次 |

**最值钱的是"立场、动机、代价"这三种**——它们同时是情感的反转:读者恨了很久的人原来一直在守护,读者以为的抛弃原来是成全。
火影里鼬的真相、哈利·波特里斯内普的记忆,都是这一类。它们要和情感债台账绑在一起设计。

### 3. 怎么造:倒着写

1. **先定真相**(写在真相层里,一句话)。
2. **再设计假象**:读者在揭开之前会相信什么?这个假象必须本身就是一个完整、讲得通的故事,而不是一团迷雾。**读者不是"不知道",是"以为自己知道"。**
3. **列事实清单**:读者会看到哪些事实。逐条检查——它在假象里讲得通吗?在真相里也讲得通吗?两边都通才留下。
4. **埋线索,至少三处,换三种样子**:
   - 藏在**笑点**里(读者忙着笑,不会琢磨);
   - 藏在**一串东西的中间**(清单的第二项、三句话的第二句);
   - 藏在**情绪高点旁边**(读者的注意力在别处);
   - 藏在**人物的怪癖**里(当成性格,其实是线索);
   - 藏在**缺了的东西**里(该叫的狗没叫,该来的人没来)。
5. **放一个更可疑的替身**:让读者把怀疑用在另一个人、另一个解释上。替身不能是硬栽的,他得有自己真实的、别的秘密。
6. **让读者先猜中一半**:给一个较浅的谜底让读者得意("我早看出来了"),真正的那一层在后面。读者防不住自己刚得意完的地方。
7. **触发**:一个新事实或一个动作,越小越好(一个称呼、一件旧物、一句说漏的话)。
8. **回放**:揭开后用两三个旧场面的一闪,让读者自己把意思改过来。不要长篇解释。
9. **后果**:人物当场必须做一个新的选择。反转之后的那一章,比反转本身更重要。

### 4. 尺度与密度

| 尺度 | 多大的反转 | 多久一次 |
|---|---|---|
| 章 | 一个"转":局面、信息或关系变了一下 | 每章 |
| 一场战斗 | 两次攻守易位 | 每场重头戏 |
| 幕(约 10 章) | 一个中等反转(目标、局中局、代价) | 每幕至多一个 |
| 卷 | 一个大反转(本卷"被看错的人"),放在全卷三分之二到五分之四处;外加两三个中等的 | 每卷 |
| 界 | 一个总反转,改写这一界读者对一切的理解 | 每界一个 |

**太密是病。** 反转一多,读者就不再相信任何东西,也就不再投入感情——反转靠的是读者的信任。两个大反转之间,要有足够长的一段"所见即所得"。

### 5. 坏反转

- **作弊**:和前面写明的事实矛盾;旁白说过谎。
- **无用**:揭开之后一切照旧。
- **为反转而反转**:和"为埋伏笔而埋伏笔"是同一种病——不知道真相就先留个"可疑",回头再圆。
- **毁人物**:为了出人意料,让一个人做出和他性格相反的事而不给理由。
- **作废感情**:让读者觉得之前的眼泪白流了。
- **只靠隐瞒**:读者猜不到,只是因为你一个字都没提。这不叫反转,叫没讲。

## 五、节奏

2026-10-03 用户:"所有都应该有节奏。进度有节奏,力量路线有节奏,剧情起伏也应该有节奏。有困难才有感动。"
第一版这一节只有几条零散的经验,没有把节奏当成一个体系。重写如下。

### 1. 总则:三条线,四个尺度

节奏不是"快慢",是**同一种东西隔多久回来一次**。一部长篇同时走着三条线,每条线在四个尺度上各有自己的拍子:

| | 章(一章之内) | 幕(约 10 章) | 卷(80~120 章) | 全书 |
|---|---|---|---|---|
| **进度线**(事情走到哪了) | 有一件事不可逆地变了 | 一个阶段目标达成或落空 | 本卷的大目标了结;倒计时走完 | 离终点近一层(世界阶梯上一格) |
| **力量线**(变强了多少) | 用出来、被克、看破一处 | **小得**:一招、一小层、一件东西 | **大破**:一个大境界或一个新形态,落在本卷高潮 | 加一层新维度 |
| **情绪线**(读者心里的起伏) | 起—承—转—钩 | 一次"压"接一次"放" | 一个谷底、一个最高点、一个让人鼻酸的地方 | 最大的那笔情感债兑现 |

三条线**不能同时平**(那一章就是水的),也**不要总是同时到顶**——让它们错开半拍:力量刚突破(力量线到顶),马上撞上更高的墙(进度线受挫);
打输了(进度线、力量线都低),却换来一句真心话(情绪线到顶)。

### 2. 进度的节奏

- **每章**至少有一样东西回不去了:知道了一件事、得罪了一个人、到了一个地方、丢了或得了一样东西。"又查到一条线索"不算。
- **每幕(约 10 章)**一个读者说得出来的阶段目标("先混进城""先凑齐三样东西""打进八强"),幕末见分晓。
- **每卷**一个大目标 + 一个倒计时;座次、赛程、楼层让读者随时知道走到哪了。
- **快慢由分量定**(节拍章数预算):过渡一章带过,重头戏三到五章。

### 3. 力量的节奏

- **三种幅度,三种间隔**:小得每 8~10 章一次;中进(小境界、一个新用法)每 25~30 章一次;大破每卷一次。间隔太密不值钱,太疏读者忘了他在变强。
- **一次完整的升级是五步,缺一步就不爽**:①**看见天花板**(亲眼见到更高一层的人出手)→ ②**碰壁**(用现有的本事输一次)→
  ③**修行或顿悟**(有过程、有代价、有笑点)→ ④**兑现**(新本事第一次亮相必须赢得痛快,让读者享受)→ ⑤**新的墙**(马上出现它也打不动的东西)。
  网文常见的毛病是只有③④:升级没有铺垫,赢了没有新墙,读者很快麻木。
- **大破与心结同步**:每卷的大突破落在本卷高潮,并且同时是主角一个心结的解开(见第一节 4)。
- **伙伴各有各的拍子**:每卷每个伙伴至少一次中进;伙伴的大破和主角的错开,不挤在同一场。

### 4. 情绪的节奏:有困难才有感动

**感动 = 在乎 × 困难 × 选择。** 三样缺一样都不成:

- **在乎**:读者得先喜欢这个人。喜欢是靠日常、玩笑、小毛病、互相挤兑攒出来的——所以轻松的章不是水,是在存钱。
- **困难**:必须是真的。真的可能输,并且真的输过、真的丢过东西。
- **选择**:感动的那一刻是一个人明知道代价还是做了选择(站出来、不跑了、把话说出口、把东西让出去)。

**"不苦大仇深"不等于"没有困难"。** 口味管的是**底色和态度**:不写虐、不写惨、不写长篇自怜,主角是笑着扛的。但困难本身必须是硬的。
不靠死人,困难从这三样来:

| 困难的种类 | 例子 | 能换来的感动 |
|---|---|---|
| **打不过** | 当众惨败;招牌招被人随手破掉;眼看着同伴挨打自己站不起来 | 再站起来的那一下 |
| **两难** | 救这个就救不了那个;守规矩就要对不起人;说真话会失去信任 | 选了,并且认了代价 |
| **失去(可挽回的)** | 师父被带走;被逐出山门;被最信的人看错;一样心爱的东西碎了;队伍被拆散 | 重逢、被认回来、有人替他说了一句话 |

**一卷的情绪曲线(W 形)**:开头轻快(存钱)→ 第一次碰壁(小谷)→ 回升、小胜、以为稳了 → **大谷底**(本卷的惨败或失去,放在三分之二处)→
谷底里的那句真心话(本卷最让人鼻酸的地方)→ 总攻与高潮 → 尾声的松快。
**一幕的曲线**:压两三章,放一章;连续压不超过四章,连续放不超过三章。
**压与放的比例**:全卷大约六成章在往上顶(难),三成在兑现(爽、笑、暖),一成是喘气的日常。

### 5. 一章之内

- **起—承—转—钩**:开场直接进事;中段一个变数;后段一个转折(局面、信息或关系变了);结尾停在"到了""来了""原来是他""他站起来了"这类时刻,不停在又一个谜上。
- **战、笑、情、谜、修**五种口味轮着来。同一种连续不超过四章(一场重头战斗是三到五章,其中至少一章是反转,最长不超过七章)。
- **该快的**:赶路、手续、交代背景、杂兵战——一两段带过。**该慢的**:抵达奇观的第一眼、入伙的那句话、决胜一击、离别。

### 5.5 最大的尺度:一浪高过一浪(2026-10-03 用户:"8 卷应该也只是第一层世界观结束。阶梯上升,宛如波涛起伏一浪一浪")

卷之上还有两层更大的浪:**部**(两三卷,以一场大战收尾)和**界**(一层世界观,约八卷)。规律是分形的——每个尺度都是"起、压、谷底、顶、落",
小浪叠在大浪上。

- **一界 = 一层完整的世界观。** 它结束时必须是一个真正的结局(这一层的谜全部揭开、最大的敌人了结、情感债兑现),
  读者合上书也不觉得被吊着;**同时**这个结局掀开一个更大的世界:原来以为的"天下"只是一角,原来以为的"真相"是更大真相的一片。
- **上一层时,三样东西一起上**:地图(更大的天地)、力量(新的一段境界与一个新维度)、真相(上一层的答案变成这一层的问题)。
- **主角在新一层重新是小人物。** 这是合法的"重置":不是把他削弱,而是天变高了。他带着上一层练出来的、别人没有的东西(那是他在新一层立足的本钱)。
- **人物不清空。** 上一层的伙伴、对手、家,分批跟上来或者成为要回去守的地方。新一层的头一卷里就要有旧人露面。
- **每一界的真相要能回头改写前一界**:读者重看上一界,会发现处处是这一层的影子。所以写第一界时,第二界、第三界的真相就得定下来(至少定到一句话)。
- 标杆:东海 → 伟大航路 → 新世界;人间界 → 灵界 → 魔界;现世 → 尸魂界 → 虚圈 → 灵王宫;传统修真的下界 → 上界 → 仙界天然就是这个结构。

### 6. 密度(写每一批章纲时逐条对)

- 小胜:任意连续四章里至少一次。大胜:十章左右一次。惨败:每卷一次大的,每幕可以有一次小的。
- 力量:小得每 8~10 章;中进每批(约 30 章)至少一次;数字和名字要报出来。
- 信息:每十章给读者一样关于这个世界的新认识;每卷揭开一块大的。
- 情:每批至少一章以"情"为主且是真到位的(不是提一句)。
- 笑:没有连续三章一个笑点都没有的。

这些密度**由程序检查**:章纲里每章要标口味、张力、胜负、所得(见任务卡 T012),导入时不合拍的会被列出来。

---

## 六、主题

每部作品有一个词(自由 / 羁绊与理解 / 守护),每个篇章的反派是这个词的一种反面,主角每次用行动而不是说教回答。
主题不出现在旁白里,只出现在选择里。

## 七、话本的设计规范(每本书的设计稿必须逐项填满;空一项不开写)

### 〇. 流派与骨架(据点战斗流)
- [ ] 家(据点)是哪里,组织是什么,主角在里面是什么身份、怎么个不守规矩法。
- [ ] 开头二三十章的小案子清单(每件立住谁、哪里好笑)。
- [ ] 固定小队三四人:各自的功夫路数;谁是前敌人、谁是又弱又重情义的、谁是比主角更酷的。
- [ ] 每卷的篇章类型(任务 / 大会考试 / 闯营营救 / 家被打上门 / 大战),相邻两卷不重样;每卷的倒计时是什么。
- [ ] 每卷的敌方小团体:座次、每席一句话人设、与小队的配对;哪几个打完会变成日后的援军。
- [ ] 主角体内那个危险的东西:失控 → 借用 → 和解 三个阶段各落在哪一卷;血脉真相。
- [ ] 大反派:他是哪一位"走歪了的前辈",与引路人的旧事。
- [ ] 组织的罪是什么,第几卷揭开,主角由此怎么变。
- [ ] 规则型能力在第几卷登场,头一个是什么规矩。
- [ ] 招牌招:谁传的、限制是什么(次数或条件)、主角后来怎么改造它;修行篇放在哪。
- [ ] 每卷的谜案:本卷那个"一直在眼前却被看错的人"是谁、真面目是什么、公平摆给读者的线索是哪三处。

### A. 力量体系
- [ ] 基础层:名字、大境界(读者一听就懂的尺度)、每一境"能打碎什么"的参照、人人可学的几门功夫。
- [ ] 至少一个"只靠基础层练到顶"的受尊敬人物。
- [ ] 神秘层:它是什么、怎么得到、为什么不可选不重样;**分类学**(3~5 类及克制关系);通用的弱点或使用条件。
- [ ] 开发层:形态阶梯(每一阶的名字与仪式)、与基础层的门槛关系(境界不够会怎样)、代价。
- [ ] 主角的神秘层:表面的解释 / 底下的真相 / 为什么开头看着没用 / 招牌招是什么(全书不换,只升级)。
- [ ] 全书的"加一层"计划:哪一卷揭开哪个新维度;哪些现象提前几卷就让读者看见但不命名。
- [ ] 力量的社会化:等级称号、机构、考试或榜单;至少两份有编号的强者名单(每个席位一句话人设)。

### B. 世界
- [ ] **世界分几界**:每一界的地图、境界段、新维度、真相(一句话)、结局是什么、怎么掀开下一界;后一界的真相如何改写前一界。
- [ ] 阶梯式地图(每卷去哪,第一卷就能让读者望见本界的终点)。
- [ ] 顶层的制衡结构(三方或四方),主角一行在其中的位置。
- [ ] 历史上的洞:缺了什么、谁在守着、真相是什么(真相层)。
- [ ] 第一卷露面的终局人物(以什么面孔)。
- [ ] 每卷所到之处的四件套:奇观、规矩、难题、有心愿的本地人。

### C. 人物
- [ ] 主角:一句话的梦、缺口、传承之物、底线、口头禅。
- [ ] 引路人:怎么离场(不写死)、留下什么、何时重逢。
- [ ] 伙伴(全书的名单):每人的梦、旧伤、能力(三层各是什么)、位子、入伙的卷、那句真心话。
- [ ] 宿敌:与主角相同的起点、相反的选择、每次回来强在哪。
- [ ] 每卷的反派:他的道理、他是主题的哪一种反面、手下干部与伙伴的配对。

### D. 框架与节奏
- [ ] 全书分几部、每部几卷、每部以什么大战收尾。
- [ ] 每卷按"抵达→卷入→摸底→谷底→过去篇→总攻→首领战→尾声"排出节拍与各节拍的章数。
- [ ] 每卷:主角与每个伙伴各升到哪一步;一次惨败在哪;世界的反应是什么。
- [ ] **全书节奏表**:每卷的难在哪(打不过 / 两难 / 失去,各是什么)、谷底在哪、那句让人鼻酸的话是谁说的、大破是什么且解开哪个心结。
- [ ] **每卷节奏表**(写卷剧本时):按幕列出阶段目标、压与放、力量的小得/中进、口味分布。
- [ ] 每批章纲:每章标口味、张力(1~5)、胜负、所得;导入时过程序检查(T012),有不合拍的先改再导。
- [ ] 每批章纲写完自检:每章结尾停在哪一类时刻;新伏笔是否都写得出真相;升级是否走完"天花板→碰壁→修行→兑现→新墙"五步。

### F. 完整性:六条线要对得上(2026-10-03 用户:"从剧情到节奏、力量架构、情节铺垫、困难、成长、感动,是需要完整的")

设计不是六张互不相干的表。一场让人记很多年的戏,是六条线在同一章里撞在一起:剧情走到关口、倒计时归零、力量大破、伏笔翻开、困难压到最底、
攒了几卷的感情兑现。所以设计稿最后必须有两样把所有东西串起来的东西:

- [ ] **情感债台账**:全书每一笔要兑现的感情,一笔一行——谁和谁(或谁和什么)、压着没说的是什么、**存钱**(哪几卷、什么样的小场面,至少三次,越日常越好)、
      **兑现**(哪一卷哪一场、那句话或那个动作)、余波。台账上没有的感情,不许临时在高潮里硬煽。
- [ ] **总谱**:一卷一行,六条线并排——进度(目标与倒计时)、力量(主角、伙伴、新维度)、困难、伏笔(埋什么、收什么)、感情(存哪几笔、兑哪一笔)、谜案。
      用它检查三件事:①每一场兑现,往前至少数得出三次存;②每卷的高潮是不是至少三条线同时到点;③有没有哪条线连着两卷没动。
- [ ] 写每一批章纲时,把总谱里这一卷该"存"的、该"埋"的分到具体的章,一条不落。

### G. 反转
- [ ] **反转台账**:每卷一个大反转 + 两三个中等的,一条一行——种类、假象(读者以为的)、真相、三处线索各藏在哪、替身是谁、触发的小东西、揭开后谁必须重新选择。
- [ ] 相邻两卷的大反转不同种类;全界至少各有一次"立场""动机""代价""价值"。
- [ ] 每个情感型反转(立场/动机/代价)在情感债台账里有对应的一笔。
- [ ] 界的总反转:它如何让读者回头重看第一卷。

### E. 伏笔与主题
- [ ] 主题一个词;每卷反派对应它的哪种反面。
- [ ] 全书级伏笔表(代号、读者看到什么、真相、首次出现、揭开);其中至少两条挂在"当时像玩笑"的东西上。
