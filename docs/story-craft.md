# 标杆作品的设定规律 → 话本的设计规范

2026-10-03 用户要求:把《海贼王》《火影忍者》《死神》这类传世长篇的复杂设定规律挖出来,补全我们欠缺的部分(力量构成、故事框架、节奏)。
起因:架构方连续三版设定被否——"当铺"只有神秘层、没有力量感;"节气"容量太小;"吃"不完整。共同的病是**只设计了一个点子,没有设计一个体系**。

本文分两部分:前六节是规律(为什么这些作品能连载上千话还让人追),第七节是规范(话本每本书的设计稿必须填满的清单)。
写全书设计(`stories/<书名>/design.md`)和每一批章纲之前,都要对照第七节。

用户的固定口味(不随书变):不要现代;有趣;不苦大仇深;爽;有想象力;要预期之外。规律里与此冲突的地方(如"导师之死"),在各条里写了怎么改。

---

## 一、力量体系

### 1. 三层复合(用户的归纳,是地基)

| | 基础层:人人都有、能练能比 | 神秘层:每人独一份、选不了 | 开发层:角色自己练出来的 |
|---|---|---|---|
| 火影 | 查克拉;体术/忍术/幻术;五种性质变化 | 尾兽、血继限界(写轮眼、白眼)、咒印、仙人体质 | 螺旋丸→大玉→风遁·螺旋手里剑;自创忍术 |
| 死神 | 灵压;斩、拳、走、鬼四门功夫 | 斩魄刀(每把有名字、有人格、形态各异);虚化;灭却师血统 | 始解→卍解;与刀对话、让刀认可 |
| 海贼王 | 体术、剑术、六式;三种霸气 | 恶魔果实(世上同时只有一颗,附带"旱鸭子"弱点) | 二档/三档/四档/五档;果实觉醒;把看似没用的能力玩出花 |

三层各管一件事:**基础层给力量感和名次,神秘层给意外和辨识度,开发层给成长和爽点**。缺基础层 = 没有力量感(当铺设定的病);
缺神秘层 = 千人一面的升级文;缺开发层 = 能力是发下来的,不是挣来的。

### 2. 基础层的规律

- **人人可及,所以努力有去处。** 没有神秘力量、只靠基础层练到顶的人物必须存在,而且要受人尊敬:小李和凯、索隆、更木剑八。
  他们证明基础层不是垫脚石。
- **基础层决定能不能驾驭神秘层。** 灵压不够卍解会压垮自己;查克拉不够开不了高级瞳术;体力不够撑不住档位。所以境界永远不白练。
- **后期基础层反过来成为决胜手。** 海贼王里霸气压过果实,越到后面越是霸气的对决。这样前期读者投入感情的基本功不会作废。
- **基础层要有读者一听就懂的尺度**:几个明确的大境界,加上看得见的破坏力参照(这一级能打碎什么)。

### 3. 神秘层的规律

- **不可选、不重样、与人物互为镜像。** 能力是性格和经历的外化:路飞的橡胶=不受拘束,一护的刀叫"斩月"而刀里藏着他的身世,
  我爱罗的沙=母亲的守护。**先定人物,再定他的能力**,不要反过来。
- **有分类学。** 无穷多的能力必须能归类,读者才理解得了、才会自己推演对决:果实分超人系/动物系/自然系;查克拉分五性质加阴阳;
  斩魄刀分直接攻击系/鬼道系。分类 3~5 种,类与类之间有粗略的克制关系。
- **每样能力都有硬弱点和使用条件。** 海水、时间限制、发动条件、必须喊出真名。弱点让以弱胜强成立,让战斗变成斗智。
- **它自己就是一条全书级伏笔。** 主角那一份的真面目到很后面才揭开(橡胶果实的真名、斩月的真相、九尾的来历与和解)。
  规则:主角的神秘层要有**表面的解释**(读者早期信以为真)和**底下的真相**(几百章后翻出来,并且回头看处处有迹可循)。
- **主角的那一份开头看着最没用,或者是个诅咒。** 橡胶被嘲笑,九尾让鸣人被全村排斥,一护的力量是借来的。爽感来自"所有人都看走了眼"。

### 4. 开发层的规律

- **形态有阶梯、有名字、有仪式。** 始解/卍解,二档/三档,仙人模式/尾兽模式。每个形态有一句解放语或起手式、一个一眼认得出的样子。
  读者期待的不是"变强",而是"下一个形态长什么样"。
- **每次大突破都同时是一个心结的解开。** 一护接纳体内的虚、鸣人与九尾和解、路飞在绝境里笑出来。**力量的钥匙在人物心里**,
  所以升级场面同时是情感高点。反过来说:没有内心事件的升级,读者记不住。
- **创造高于天赋。** 主角的招是自己琢磨出来的(把橡胶当泵用、把螺旋丸掺进风),经常来自失败、玩笑或别人的一句话。
- **代价明码标价。** 二档折寿、八门遁甲烧命、卍解时间有限。强招不能随便用,所以什么时候用成了戏。
- **老招不淘汰。** 螺旋丸从头用到尾,只是越变越大;橡胶手枪到最后还是那一拳。招牌招是人物的签名,升级的是它,不是换掉它。

### 5. 整个体系的规律

- **规则早公开,上限晚揭晓。** 读者很早就知道体系的基本规则(可以推演、可以争论),但更高的层次是一层层揭开的。
  而且常常是**先看见现象、几百章后才命名**:香克斯第一话瞪退海王类,"霸气"这个词很久以后才出现。回头看,作者早就知道。
- **膨胀靠"加一层",不靠"数字变大"。** 新阶段引入的是新维度(霸气、仙术、觉醒),而不是把旧数字乘十。于是老人物只要补上新维度就能跟上,不会作废。
- **强者一直都在,只是在更远的地方。** 世界阶梯(东海→伟大航路→新世界)保证新对手不是凭空冒出来的:他们早就被提到过名字。
- **战力不是一个数。** 有粗略的社会标签(悬赏金、下忍/中忍/上忍、队长/副队长),但标签经常不准——这是惊喜的来源。相性、情报、意志能翻盘。
- **力量嵌在社会里。** 忍者有村子、任务等级、考试;死神有十三队和番号;海贼有悬赏、海军、七武海、四皇。力量体系同时是职业体系、政治体系、经济体系。
  读者认识世界的方式就是认识"谁在哪个位子上"。
- **有编号的强者名单。** 十刃、晓、七武海、十三队队长、超新星。名单制造收集欲:读者会数"还有几个没出场""谁对谁"。每个席位的人设与能力必须一眼分得开。

## 二、世界

1. **阶梯式地图,而且早早亮给读者看。** 第一卷读者就知道世界有几层、终点在哪(伟大航路的尽头、五大国、尸魂界)。地图本身是对读者的承诺:你知道故事会去哪,只是不知道那里有什么。
2. **顶层有制衡结构。** 海军—七武海—四皇;五大国—晓;护廷十三队—虚圈—灭却师。主角一行是在几大势力夹缝里移动的小团体,每到一处都会扰动平衡。
3. **每个地方 = 一种奇观 + 一条本地规矩 + 一个本地的压迫或难题 + 一个有心愿的本地人。** 空岛、鱼人岛、波之国。主角不是去"打怪",是撞进一个地方的问题里。
4. **历史上有一个洞。** 空白的一百年、六道仙人、灵王。世界的过去缺了一块,有一个机构在守着这个谎。真相层就是这段历史,全书的大伏笔都指向它。
5. **终局人物第一卷就露面,而且往往是善意的面孔。** 香克斯、蓝染队长、带着面具的"阿飞"。等他的真实位置揭开时,读者会回头重读第一卷。
6. **世界会对主角的行动作出反应。** 每个大篇章结束,镜头切到别处:新的悬赏令、各方大人物的议论、报纸传遍四海。主角的成长因此是"被世界看见"的,这是长篇里最稳定的爽点之一。

## 三、人物

1. **主角:一句话的梦,第一章就喊出来,永不动摇。** "我要成为海贼王""我要当火影"。性格简单明亮,行动先于思考;身上有一处缺(孤独、被排斥)但不自怜。
   有一件**传承之物**(草帽、护额),来自一个早早离场的引路人——物件在,承诺就在。
2. **伙伴:每人 = 一个梦 + 一道旧伤 + 一个只属于他的篇章 + 团队里一个无可替代的位子。** 入伙的那一刻是他把压了很久的真心喊出来("我想活下去""帮帮我"),
   主角的回应永远是无条件的行动。伙伴的过去放在决战之前讲,给接下来那一拳装上重量。
3. **宿敌是主角的另一种可能。** 佐助和鸣人同样孤独,作了相反的选择。宿敌贯穿全书,每隔一段回来一次且更强,最后的和解或决战是全书情感的顶点。
4. **反派有道理,而且他的道理正好是主题的反面。** 佩恩的"痛才能带来和平"对鸣人的"互相理解";大反派有魅力、有信念,打败他需要主角先回答他的问题。
5. **群像靠辨识度。** 每个人一个剪影、一个口癖或笑声、一个执念。出场三句话内读者要能认出是谁。
6. **情感债的公式:压抑 N 章 → 一句话爆发 → 主角用行动回应。** 压得越久,那一句越值钱。全书最被记住的场面都是这个结构。
7. **引路人离场。** 标杆作品常用"导师之死"(自来也、艾斯)。**话本不写这个**(用户不要苦大仇深):改成失散、沉睡、被困、主动远行——
   同样提供"必须自己长大"的推力和一个重逢的远期承诺。

## 四、故事框架

### 1. 一个篇章(=话本的一卷)的标准骨架

1. **抵达**:新地方的奇观、规矩、一个有心愿的本地人。(轻快,笑点多)
2. **卷入**:本地的压迫者或难题露面;主角一行第一次碰壁——输一场、被分开、或者眼看着不公发生却无能为力。
3. **摸底**:知道了对手是谁、有几个干部、各自什么本事;伙伴们各自找到自己的对手(配对)。
4. **谷底**:最坏的事发生了;那个本地人(或某个伙伴)说出压了很久的真心话。
5. **过去篇**:在总攻之前,讲清楚这个人为什么是这样。
6. **总攻**:多条线一对一同时打,从弱到强依次结算;每一场是情报战(看懂对方能力 → 找到破绽 → 对方亮底牌 → 自己亮新招)。
7. **主角对首领**:分两三个回合,中间有一次反转;决胜一击落在新形态或新招的首次亮相上,并且呼应前面的心结。
8. **尾声**:宴会或告别;世界的反应(名声、通缉、各方议论);下一站的钩子。新伙伴上船。

### 2. 更大的结构

- **篇章有长有短,交替出现。** 大长篇之后接一个短而轻的,让读者喘气;若干篇章汇成一个"部",以一场所有人都卷进来的大战收尾(顶上战争、忍界大战)。
- **最强的两种发动机:营救与试炼。**
  - 营救(救露琪亚、救罗宾、追回佐助):目标清楚、有时限、敌人的据点一层层守关者——天然产生配对战和倒计时。
  - 试炼/大会(中忍考试):一次性展示同辈人、宿敌、各家本事和世界格局;然后**被一个更大的阴谋打断**。
- **修行与时间跳跃。** 一次惨败之后,主角一行分开修行,隔一段时间重聚:人人换了新样子、新本事。这是合法的"重置战力并制造期待"的手段。
- **开篇三十章要完成的事**:主角的梦和传承之物;力量体系的基本规则和主角那份"没用"的神秘力量;头两个伙伴;第一个让人恨的对手和第一次像样的胜利;
  世界阶梯和顶层格局的一瞥;至少一个终局人物露面。

### 3. 伏笔

- 最好的伏笔是**当时看着像玩笑或闲笔的东西**,回收时改变旧场面的意思。
- 大伏笔挂在**物件、名字、历史**上,而不是挂在"神秘人影"上。
- 一次只让读者盯着两三个大问号;小问号快埋快收,给读者"作者说话算话"的信任,他们才愿意等大问号。

## 五、节奏

1. **每章结尾停在"到了""来了""原来是他""他站起来了"这类时刻**:抵达、登场、揭示、转折。不是停在又一个谜上。
2. **战、笑、情三种章轮着来。** 连续三章同一种口味读者就疲。紧张的地方插一句不合时宜的笑话,是这类作品的标志性呼吸。
3. **该快的:赶路、手续、交代背景、杂兵战**——一两段带过。**该慢的:抵达奇观的第一眼、入伙的那句话、决胜一击、离别**——舍得给篇幅。
4. **一场重头战斗的篇幅**:三到五章,其中至少一章是反转;不超过七章。干部战一到两章。
5. **胜利的密度**:小胜两三章一次,大胜十章左右一次,一卷之内必须有一次真正的惨败。
6. **信息的节奏**:每十章左右给读者一样"关于这个世界的新认识";每卷揭开一块大的。

---

## 六、主题

每部作品有一个词(自由 / 羁绊与理解 / 守护),每个篇章的反派是这个词的一种反面,主角每次用行动而不是说教回答。
主题不出现在旁白里,只出现在选择里。

## 七、话本的设计规范(每本书的设计稿必须逐项填满;空一项不开写)

### A. 力量体系
- [ ] 基础层:名字、大境界(读者一听就懂的尺度)、每一境"能打碎什么"的参照、人人可学的几门功夫。
- [ ] 至少一个"只靠基础层练到顶"的受尊敬人物。
- [ ] 神秘层:它是什么、怎么得到、为什么不可选不重样;**分类学**(3~5 类及克制关系);通用的弱点或使用条件。
- [ ] 开发层:形态阶梯(每一阶的名字与仪式)、与基础层的门槛关系(境界不够会怎样)、代价。
- [ ] 主角的神秘层:表面的解释 / 底下的真相 / 为什么开头看着没用 / 招牌招是什么(全书不换,只升级)。
- [ ] 全书的"加一层"计划:哪一卷揭开哪个新维度;哪些现象提前几卷就让读者看见但不命名。
- [ ] 力量的社会化:等级称号、机构、考试或榜单;至少两份有编号的强者名单(每个席位一句话人设)。

### B. 世界
- [ ] 阶梯式地图(每卷去哪,第一卷就能让读者望见终点)。
- [ ] 顶层的制衡结构(三方或四方),主角一行在其中的位置。
- [ ] 历史上的洞:缺了什么、谁在守着、真相是什么(真相层)。
- [ ] 第一卷露面的终局人物(以什么面孔)。
- [ ] 每卷所到之处的四件套:奇观、规矩、难题、有心愿的本地人。

### C. 人物
- [ ] 主角:一句话的梦、缺口、传承之物、底线、口头禅。
- [ ] 引路人:怎么离场(不写死)、留下什么、何时重逢。
- [ ] 伙伴(全书的名单):每人的梦、旧伤、能力(三层各是什么)、位子、入伙的卷、那句真心话。
- [ ] 宿敌:与主角相同的起点、相反的选择、每次回来强在哪。
- [ ] 每卷的反派:他的道理、他是主题的哪一种反面、手下干部与伙伴的配对。

### D. 框架与节奏
- [ ] 全书分几部、每部几卷、每部以什么大战收尾。
- [ ] 每卷按"抵达→卷入→摸底→谷底→过去篇→总攻→首领战→尾声"排出节拍与各节拍的章数。
- [ ] 每卷:主角与每个伙伴各升到哪一步;一次惨败在哪;世界的反应是什么。
- [ ] 每批章纲写完自检:战/笑/情有没有轮开;每章结尾停在哪一类时刻;小胜大胜的密度;新伏笔是否都写得出真相。

### E. 伏笔与主题
- [ ] 主题一个词;每卷反派对应它的哪种反面。
- [ ] 全书级伏笔表(代号、读者看到什么、真相、首次出现、揭开);其中至少两条挂在"当时像玩笑"的东西上。
