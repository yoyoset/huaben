# T019 原话比对:半角与全角标点算同一个

依赖:无。

## 为什么

T014 的原话比对(`huaben/verbatim.py`)只忽略空白和引号。章纲的 `lines` 若写了半角逗号或问号(架构方手写时的习惯),
而正文是全角,就永远"缺原话"、被白白打回。2026-10-03 导入《弄假成真》时踩过,当时靠把章纲改成全角绕开
(见 `stories/弄假成真/notes.md`"已知但暂不处理")。这张卡把它修掉。

## 已定的方案

只改 `huaben/verbatim.py` 的 `_squash`:去掉空白与引号**之前**,先把下面这些半角标点换成对应的全角(用 `str.translate`,表做成模块级常量):

| 半角 | 全角 | 全角的码位 |
|---|---|---|
| `,` | `，` | U+FF0C |
| `?` | `？` | U+FF1F |
| `!` | `！` | U+FF01 |
| `:` | `：` | U+FF1A |
| `;` | `；` | U+FF1B |
| `(` | `（` | U+FF08 |
| `)` | `）` | U+FF09 |

句号不动(半角 `.` 会出现在数字和省略里)。`missing_lines` 与 `ending_problem` 都走 `_squash`,所以两处一起生效,别的不用改。

## 测试(加在 `tests/test_verbatim.py`)

- 章纲原话 `"戏不错,跟我走一趟?"`(半角逗号、半角问号),正文里是 `戏不错，跟我走一趟？`(全角) → `missing_lines` 返回空。
- 反过来:章纲全角、正文半角 → 也返回空。
- 字不一样("戏不错" 对 "戏不赖")→ 仍然报缺。
- `ending_problem`:章纲结尾半角标点、正文结尾全角 → 返回空。
- 现有测试原样通过。
