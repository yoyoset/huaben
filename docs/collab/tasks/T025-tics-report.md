# T025 口头禅统计:一个只读的小工具

依赖:无。

## 为什么

《弄假成真》第 3~30 章回看时发现"一动不动""一级一级 / 一滴一滴"这类写法后半段很密(第 30 章叠用 21 处)。
接句工具只动标点,管不了这个;架构方手改之前需要一张"哪一章、哪种写法、多少处"的表。这张卡只做统计,不改任何正文,不接进写章流程。

## 已定的方案

### 1. 纯函数(新建 `huaben/tics.py`)

```python
FIXED = ("一动不动", "慢慢", "一点一点", "一字一字", "没有说话", "没说话", "很久")   # 逐字数的固定说法
REDUP = re.compile(r"一(.)[，、]?一\1")   # 叠用:一级一级、一滴,一滴、一下、一下
REDUP_LIMIT = 2.0                          # 每千字叠用超过这个数就标出来


def tic_counts(text: str) -> dict:
    """返回 {"chars": 非空白字数, "redup": 叠用处数, "redup_per_k": 每千字叠用(保留一位小数),
            "fixed": {说法: 次数}(只列出现过的), "top_redup": 出现最多的 3 种叠用 [(写法, 次数)]}"""


def tic_report(chapters: dict[int, str]) -> list[str]:
    """{章号: 正文} → 每章一行的文字报告,按章号排序;最后一行是合计。"""
```

- "非空白字数" = `re.sub(r"\s", "", text)` 的长度;为 0 时 `redup_per_k` 是 0.0。
- `top_redup` 里的"写法"归一成不带标点的四个字(例如"一滴,一滴"记成"一滴一滴")。
- 报告每章一行的格式(一字不差):

  `第{章号:02d}章 叠用 {redup} 处(每千字 {redup_per_k}){标记} 最多:{写法}×{次数}、… 固定说法:{说法}×{次数}、…`

  `{标记}` 在 `redup_per_k > REDUP_LIMIT` 时是 `【密】`,否则为空;某一项没有内容时写 `无`。
  合计行:`合计 叠用 {总处数} 处;超过每千字 {REDUP_LIMIT} 的章:{章号用顿号隔开,没有写"无"}`。

### 2. 命令行(同一个文件里的 `main`,`python -m huaben.tics <目录>`)

读目录下的 `NN.txt`(两位章号,UTF-8),打印 `tic_report` 的每一行。输出要能在 Windows 控制台不乱码:
照 `huaben/rhythm.py` 的 `main` 写法,但在打印前加 `sys.stdout.reconfigure(encoding="utf-8")`。目录不存在或里面没有 `NN.txt` → 打印一行说明并返回 1。

### 3. 测试(新建 `tests/test_tics.py`)

- `tic_counts("他一级一级往上走。血一滴，一滴，落下来。他一动不动。")`:`redup == 2`;`fixed == {"一动不动": 1}`;`top_redup` 里有 `("一级一级", 1)` 和 `("一滴一滴", 1)`。
- 空文本:`chars == 0`、`redup_per_k == 0.0`。
- 1000 个非空白字里有 3 处叠用 → 报告那一行含 `【密】`;只有 1 处 → 不含。
- `tic_report`:两章,章号乱序传入 → 输出按章号排序,最后一行以 `合计` 开头。
- 命令行:临时目录里放两个 `NN.txt` → 返回 0;空目录 → 返回 1。
