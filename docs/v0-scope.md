# v0 范围

目标:**在 13 上跑起来,能开一本书、一键连载、锁屏听。**验证三件事:分层记忆 + 账本是否真的减少遗忘;风格样章是否起作用;PWA 锁屏听书是否可用。

## 做

1. **开书对话**:引导式对话产出故事圣经(世界观、人物卡、风格指纹 + 样章片段)与第一卷规划。
2. **一键连载**:编辑·章纲 → 作者·正文 → 编辑·入账 的流水线;分层记忆;伏笔账本;封卷。
3. **预生成缓冲**:后台始终多备好 3 章正文 + 音频。
4. **保底语音**:Python `edge-tts` 直接出 MP3(晓晓),按章生成。
5. **PWA 阅读/播放器**:书架、章节阅读、播放(Media Session 锁屏控制、自动下一章、睡眠定时)。
6. **部署**:13 上 Docker Compose,每日备份到 `/mnt/4t/backups/huaben`,Tailscale 访问。
7. **可观测**:每章记录各步耗时、token、费用、核对结果——用来回答"贵不贵、慢不慢、账本有没有用"。

## 不做(及理由)

| 不做 | 理由 |
|---|---|
| APK / 原生 App | PWA 双平台够用;先验证产品再谈壳 |
| 账号系统、密码、分享 | 家用,Tailscale 已解决远程访问。(2026-10-02 起**做**了"每人一个书架"的 profile,无密码——用户要求,见 architecture.md 第 1 节) |
| PC GPU 高质量语音工人 | v1;v0 先用保底语音验证"听"的完整链路 |
| 导演脚本 / 多角色配音 | v1,依赖高质量语音选型 |
| 「不好看」品控反馈 | v1;先有真实使用再看要哪些理由选项 |
| 中途引导剧情 | 用户明确不关心;做成设置项也放到 v1 以后 |
| 迁移酒馆里的旧书/存档 | 酒馆继续并行使用;话本从开书对话重新开始 |

## 验收(v0 跑通的标准)

- 一本书连续生成 ≥30 章,人工抽查:无非计划的人名错误/死人复活;卷内伏笔有回收记录。
- 风格:同一开书设定,"有样章"与"无样章"各生成 3 章,盲读能分辨出差别。
- 苹果和安卓真机:锁屏后能继续播、自动下一章。
- 记录到单章平均成本与耗时。
